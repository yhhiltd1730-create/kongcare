# 콩케어 공익 데이터·정책 인사이트 전략 v1.0

STATUS: ACTIVE_DIRECTION
SCOPE: 콩케어 사용자 이용데이터를 개인 식별 없이 분석하여 병원·지자체·정부·복지기관의 정책·서비스 개선에 활용
CORE_RULE: 개인을 추적하지 않고, 집단 수준의 수요·누락·불편·정책 접근성 문제를 분석한다.

## 1. 목표
콩케어를 단순 정보검색 앱이 아니라,
"장애인이 실제로 무엇을 찾고, 어디에서 막히며, 어떤 지원이 부족한지"를 비식별·집계 데이터로 보여주는 정책 인텔리전스 플랫폼으로 확장한다.

## 2. 분석 가능한 핵심 데이터
개인정보를 직접 수집하지 않는 범위에서 우선 수집:
- 지역(시도/시군구 수준)
- 찾은 정책 카테고리
- 장애유형(선택형, 선택사항)
- 사용자 역할(본인/보호자/기관직원)
- 검색 키워드/의도 분류(비식별)
- 혜택카드 조회/클릭
- 신청경로 클릭
- 실패한 검색
- "정보 부족/이해 어려움/정책오류 의심" 피드백
- 결과 도달 시간
- 정책별 관심도
- 지역별 미충족 검색
- 정책 변경/만료 발견 빈도
- 접근성 문제 유형
- 기기/화면크기/OS 범주(식별자 없이)
- 세션 단위 익명 이벤트

원칙:
- 주민번호/전화/이름/정확한 주소/상세진단/병력은 분석 목적 수집 금지
- 원문 자유텍스트는 가능하면 즉시 범주화 후 원문 최소보존
- 소수집단 재식별 위험이 있는 통계는 공개/기관제공 시 최소집단크기 기준 적용

## 3. 정책 인사이트 계층
L1 DESCRIPTIVE
- 무엇을 많이 찾는가
- 어느 지역에서 어떤 지원 수요가 높은가
- 어떤 정책이 많이 조회되는가

L2 FRICTION
- 어디서 사용자가 이탈하는가
- 정책은 있는데 이해/신청이 어려운가
- 신청 경로/링크/서류가 복잡한가

L3 GAP
- 검색 수요는 많은데 대응 정책이 없는 영역
- 지역 간 지원 격차
- 장애유형별 정보 접근 격차
- 반복적으로 UNKNOWN이 발생하는 영역

L4 PREDICTIVE
- 정책 수요 변화 추세
- 특정 지역의 지원수요 증가 신호
- 계절/시기별 복지 수요 패턴
주의: 개인 예측이 아니라 집단/지역 단위 분석

L5 PRESCRIPTIVE
- 우선 개선할 정책/서비스 후보
- 상담 인력/콘텐츠 보강 우선순위
- 신청절차 단순화 후보
- 신규 정책/예산 검토 후보
- 정보전달 채널 개선안

## 4. 기관 제공 리포트
### 병원
- 환자가 많이 찾는 복지/지원
- 퇴원/통원 후 지원 공백
- 상담 반복질문 Top N
- 지역별 지원 연결률
- 정책/링크 오류 현황
- 환자 안내 동선 개선 제안

### 지자체
- 지역 장애인 수요지도
- 정책별 관심/접근/실패율
- 미충족 수요 Top N
- 지역 내 정보공백
- 읍면동 단위 비교는 재식별 위험이 낮을 때만
- 정책 개선 우선순위 후보

### 정부/광역
- 지역 간 정책 격차
- 전국 공통 수요
- 장애유형별 접근성 차이
- 반복적으로 발생하는 제도/신청 병목
- 정책 홍보 도달성
- 정책 신설/개편 검토 후보

## 5. 정책 제안 엔진
입력:
USAGE SIGNALS + POLICY CATALOG + USER FEEDBACK + REGION COVERAGE + ACCESSIBILITY ISSUES

처리:
1. 수요량
2. 실패/이탈
3. 정책공급 여부
4. 지역격차
5. 중복/사각지대
6. 영향도
7. 개선 난이도
8. 근거 신뢰도

출력:
- OBSERVATION
- EVIDENCE
- AFFECTED GROUP
- POLICY GAP
- OPTIONS
- EXPECTED IMPACT
- COST/COMPLEXITY RANGE
- RISKS
- RECOMMENDED PILOT
- MEASUREMENT PLAN

주의:
콩케어는 "정책 결론"을 자동 확정하지 않는다.
정책 방향 후보와 근거를 제시하고 최종 결정은 기관이 한다.

## 6. 데이터 상품
무료/공익:
- 전국 장애인 복지 수요 공개 대시보드(고도 집계)
- 지역별 정책 접근성 지표
- 정보공백/접근성 이슈 공개 리포트

유료 B2B/B2G:
- 기관별 상세 분석 대시보드
- 정책 Gap 분석
- 비교 벤치마크
- 월간/분기 정책 인사이트 리포트
- 정책 변화 전후 효과 측정
- 맞춤형 시범사업 설계 지원
- API / 정기 데이터팩

## 7. 프라이버시·윤리 Guard
- 데이터 최소수집
- 목적 외 사용 금지
- 민감정보 판매 금지
- 개인 프로파일링 금지
- 개별 장애인 점수화/위험등급화 금지
- 소수집단 재식별 방지
- 통계 최소집단크기/노이즈/범주화 검토
- 기관 계약보다 사용자 권익 우선
- 데이터 사용 목적/보유기간/제공범위 투명화
- 삭제/철회 구조
- 분석 결과가 지원 축소의 근거로 악용되지 않도록 공익성 검토

## 8. MVP 분석 대시보드
첫 버전 지표:
1. 일/주/월 활성 세션
2. 지역별 조회량
3. 정책 카테고리별 수요
4. 검색 실패율
5. UNKNOWN 응답률
6. 신청경로 클릭률
7. 정책오류 신고율
8. 접근성 이슈율
9. 평균 과업완료시간
10. 미충족 수요 Top 20

## 9. 단계
P0 DEMO:
synthetic/event mock으로 분석화면 제작

P1 CLOSED BETA:
익명 이벤트만 실제 수집, 민감정보 없음

P2 HOSPITAL PILOT:
병원별 비식별 집계 리포트

P3 LOCAL GOV PILOT:
여수/전남 지역 수요/정책 Gap 분석

P4 NATIONAL:
전국 비교/정책 인사이트 플랫폼

## 10. 성공 기준
- 개인 식별 없이 의미 있는 정책수요 신호 확보
- 정책 Gap 후보를 근거와 함께 설명 가능
- 기관이 실제 개선조치를 선택할 수 있는 수준의 리포트
- 정책 변경 전/후 효과 측정 가능
- 사용자 권익을 훼손하지 않는 수익모델 유지

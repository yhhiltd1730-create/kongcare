# 콩케어 여수한국병원 DEMO 제안서 초안 v0.1

## 제안 목적
환자와 보호자가 복지·의료비·교통·장애지원 정보를 더 쉽게 찾도록 하는 콩케어 개선형 데모를 여수한국병원 현장에서 제한적으로 검증합니다.

## 병원에 필요한 이유
- 반복되는 복지/지원 질문을 더 쉽게 안내
- 환자·보호자가 스스로 확인 가능한 경로 제공
- 공식출처/기준일 중심으로 잘못된 안내 위험 감소
- 개인정보 없이도 초기 Pilot 가능
- 실제 사용 데이터를 비식별 집계해 상담/지원 공백 파악 가능

## 데모 범위
- 투석·신장지원
- 의료비/산정특례
- 장애등록/연금
- 교통지원
- 긴급복지
- 보호자 보기
- 공식기관 Direct 링크

## 병원 부담 최소화
- 병원 시스템 연동 없음
- 환자 개인정보 수집 없음
- 초기 별도 계정 없음
- QR/링크 기반 데모 가능
- 문제 발생 시 즉시 데모 중단/수정 가능

## Pilot KPI
- 첫 도움경로 도달시간
- 핵심 과업 성공률
- 반복질문 Top N
- 정책/링크 오류
- 접근성 문제
- 사용자 만족/불편

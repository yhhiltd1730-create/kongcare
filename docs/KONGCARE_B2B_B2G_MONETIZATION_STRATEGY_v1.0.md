# 콩케어 B2B/B2G 수익화 전략 v1.0

## 포지셔닝
개인에게 돈을 받는 앱이 아니라, 병원·지자체·복지기관이 장애인에게 더 정확하고 빠른 안내를 제공하도록 돕는 기관용 플랫폼.

## 개인 사용자
- 무료
- 비로그인 핵심기능
- 광고 때문에 복지정보 순위가 바뀌지 않음
- 민감정보 판매 없음

## 병원 패키지
### H1 DEMO
- 환자용 복지안내
- 신장/투석 전문팩
- 지역지원
- 공식출처
- 피드백
가격: 무료/시범

### H2 PILOT
- 직원상담 모드
- QR 공유
- 정책 최신성
- 오류신고
- 비식별 이용지표
가격: 시범계약 또는 소액 PoC

### H3 HOSPITAL PRO
- 병원별 관리자
- RBAC/감사로그
- 지역/질환별 정책팩
- 정책 변경감시
- 상담지원
- SLA/유지보수
가격: 월/연 SaaS + 초기 구축

## 정부/지자체 패키지
### G1 LOCAL DEMO
- 지역 정책 포털
- 접근성 UX
- 지역팩

### G2 PILOT
- 정책 CMS
- 변경감지
- 오류정정
- 비식별 사용성 지표

### G3 GOVERNMENT PRO
- 다기관/다지역 운영
- 승인 워크플로
- 정책 품질지표
- API
- 감사로그/권한
- SLA

## 영업 우선순위
1. 현재 실제 사용처인 병원 데모
2. 여수/전남 병원·복지기관
3. 여수시/전남도 등 지자체
4. 타 지역 병원/복지관
5. 전국 단위 공공사업

## 계약 전 증거
- 현장 Demo
- 사용자 피드백
- 과업성공률
- 정책 정확도
- 접근성 테스트
- 보안 P0
- 운영/복구 증거

## 핵심 가치제안
병원: 상담시간 단축 + 환자 만족 + 놓치는 복지 감소
지자체: 정책 전달률 향상 + 정보 최신성 + 접근성 강화 + 상담업무 효율화
사용자: 무료 + 쉬운 접근 + 공식근거 + 실제 신청경로

## 금지
- 개인 유료벽으로 핵심 복지정보 제한
- 리드판매
- 민감정보 판매
- 유료 광고 우선노출
- 무허가 병원/정부 제휴표현

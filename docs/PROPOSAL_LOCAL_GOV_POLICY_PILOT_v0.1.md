# 콩케어 지자체 정책 Pilot 제안서 초안 v0.1

## 제안 목적
장애인이 실제로 무엇을 찾고 어디서 막히는지 비식별 집계 데이터로 분석해 지역 복지정책의 정보접근성과 전달효율을 개선합니다.

## 지자체 가치
- 지역별 복지 수요 파악
- 정책별 검색/이탈/UNKNOWN 분석
- 정보 사각지대 탐지
- 반복민원/상담업무 개선
- 정책 변경/만료 정보 품질관리
- 접근성 강화형 주민 서비스

## 제공 기능
- 시민용 무료 콩케어
- 지역 정책팩
- 관리자 CMS
- 정책 변경감지
- 비식별 수요대시보드
- 정책 Gap/개선 후보 리포트
- Pilot 전/후 KPI 측정

## 데이터 원칙
개인을 추적하지 않고 집단수준의 수요·불편·정책접근성만 분석합니다.
민감정보 판매/개인 프로파일링은 하지 않습니다.

## 단계
LOCAL DEMO -> POLICY PILOT -> GOVERNMENT PRO

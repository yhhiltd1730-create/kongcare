# 콩케어 전국 상용화 실행 로드맵 v1.0

## 현실적 기간
현재 단일페이지 PWA를 출발점으로 할 때:

- 0~2주: FOUNDATION
  - 정보구조/디자인시스템
  - 보안 P0
  - 전국 정책 데이터 스키마
  - 접근성 기준/테스트 하네스
  - 지역/장애유형 선택기
  - 신장·투석 기존 콘텐츠 마이그레이션

- 3~6주: NATIONAL MVP
  - 전국/광역/기초자치단체 구조
  - 혜택 검색/필터
  - 쉬운글/큰글씨/스크린리더
  - 정책 출처/기준일/변경상태
  - 말로 질문하기 초안
  - 운영자 CMS 초안

- 7~10주: PILOT
  - 전남/광주 + 추가 2~3개 권역
  - 실제 장애유형 사용자 시나리오
  - 정책 변경 감시
  - 보호자 모드
  - 장애/저속망/복구 테스트
  - 보안·개인정보 점검

- 11~16주: PUBLIC BETA
  - 전국 정책 커버리지 확대
  - 음성/대화 Golden E2E
  - 기관/병원/복지관 시범
  - 접근성 실사용 검증
  - 성능/관측/운영 대응

- 4~6개월: COMMERCIAL V1
  - 전국형 운영
  - B2B/B2G 관리자 대시보드
  - 정책 품질 SLA
  - 사용자 문의/신고/정정 루프
  - 약관/개인정보/보안/접근성 출시 Gate

## 일정 판정
- "쓸 수 있는 전국 MVP": 6주 목표
- "실사용 베타": 10~16주
- "돈을 받고 기관에 제공 가능한 V1": 4~6개월
- 전국 모든 지역 정책의 높은 정확도까지는 지속 운영 과제이며 일회성 개발 완료로 간주하지 않음.

## Phase 1 Critical Path
1. client-side admin PIN 제거/관리자 기능 격리
2. 정책 데이터 모델 분리 (HTML 하드코딩 탈피)
3. 디자인시스템/접근성 컴포넌트
4. 지역 선택/정책 라우팅
5. 공식원문 ingestion + 검증상태
6. 혜택 검색/체크리스트
7. 음성/대화 read-only
8. 운영 CMS
9. 실제 사용자 테스트
10. 전국 확장

## Human Gate
아래는 자동배포 금지:
- production 배포
- 신규 유료서비스/API 비용
- 개인정보 수집 시작
- 외부기관 제휴/계약/제출
- 도메인/결제
- 실제 사용자 민감정보 처리

# 여수한국병원 우선 데모·베타 실행계획 v1.0

STATUS: ACTIVE_PREP
BASE_DATE: 2026-09-24
SCOPE: 기존 콩케어 사용자 흐름을 보존하면서 여수한국병원 현장 데모를 우선 만들고, 그 결과를 전국형 V2에 환류한다.
IMPORTANT: 병원 명칭 사용은 "현장 데모용/테스트용" 표시로 한정하며 병원 공식 제휴·승인으로 오인시키지 않는다. 실제 병원 배포/게시/QR 부착/직원 안내는 OWNER 승인 및 병원 측 허용 확인 후 진행한다.

## 목표
1. 기존 사용자에게 낯설지 않은 병원용 데모를 먼저 제공한다.
2. 환자/보호자가 30초 안에 필요한 혜택 또는 도움 경로를 찾게 한다.
3. 실제 현장 피드백을 전국형 V2 설계에 즉시 반영한다.
4. 각 단계는 Demo -> Test -> Evidence -> Fix -> Next Gate로 닫는다.

## 단계별 일정

### D0 — TODAY / 2026-09-24: 병원 데모 쉘
목표:
- 여수한국병원 현장 데모 화면
- 기존 콩케어 핵심 9개 항목 보존
- "투석·신장 / 교통 / 의료비 / 장애·연금 / 긴급" 빠른 진입
- 큰 글씨 / 단순 버튼 / 비로그인
- 공식출처 우선
완료조건:
- 클릭 가능한 standalone demo
- 병원 공식서비스가 아니라는 테스트 표기
- 개인정보 입력 없음
- 관리자 기능 없음

### D1 — 2026-09-25~09-26: PATIENT DEMO v1
목표:
- 환자/보호자용 첫 화면 완성
- 30초 과업: "내가 받을 수 있는 혜택 찾기"
- 여수/전남 지역팩 + 신장·투석 전문팩
- 준비서류/어디로/전화/공식링크 카드
- 쉬운글/큰글씨/스크린리더 baseline
테스트:
- 5개 Golden 사용자 시나리오
- 모바일 360px / 큰글씨 / 오프라인 오류
- 링크 건강성 샘플 검사

### D2 — 2026-09-27~09-28: STAFF DEMO v2
목표:
- 병원 원무/사회복지/간호 상담 시 보여주기 쉬운 구조
- "환자에게 보여주기" 모드
- QR/링크 공유
- 정책 기준일/출처/확인필요 상태
- 개인정보 없이 상담 가능
테스트:
- 상담자 3분 이내 설명 가능
- 잘못된 "수급 확정" 표현 0
- 공식근거 없는 정책카드 0

### D3 — 2026-09-29~10-01: CLOSED BETA
대상:
- OWNER가 허용한 소수 사용자/보호자 테스트
- 병원 공식 제휴로 오인되지 않는 제한된 테스트
수집:
- 과업성공/실패
- 찾는 데 걸린 시간
- 글씨/버튼/용어 불편
- 누락 혜택
- 잘못된/오래된 정책
금지:
- 주민번호/전화/진단정보 수집
- 실제 민감정보 저장
- 병원 시스템 연결
PASS 기준:
- 핵심 과업 성공률 >= 90% 목표
- 접근성 Blocker 0
- P0 오정보 0
- Critical/High 보안결함 0

### D4 — 2026-10-02~10-07: HOSPITAL PILOT CANDIDATE
목표:
- 실제 병원 현장에 보여줄 수 있는 Pilot 후보
- 정책변경 감지/검토 흐름
- 오류신고/정정요청
- 사용성 지표 대시보드 초안(개인정보 없이 집계)
Human Gate:
- 병원 공식 배포/QR 게시/직원 교육/외부 안내 전 OWNER 승인 + 병원 측 허용 확인

### D5 — 2026-10-08~10-21: YEOSU/JEONNAM BETA
목표:
- 여수한국병원 데모에서 얻은 피드백을 지역팩에 반영
- 여수/전남 장애인 전반으로 확장
- 신장장애에서 전 장애유형 UI로 전환
- 지역 정책 커버리지 표시
PASS:
- 지역 Golden E2E
- UNKNOWN/확인필요 정직 표시
- rollback/recovery 검증

### D6 — 2026-10-22~11-07: NATIONAL PUBLIC BETA CANDIDATE
목표:
- 전국 지역 구조
- 중앙정책 + 우선지역팩
- 전 장애유형
- 보호자 모드
- 음성/대화 Read-only
- 접근성 실사용 검증 1차

### D7 — 2026-11~12월: COMMERCIAL V1 CANDIDATE
목표:
- 기관용 관리자/CMS
- RBAC/감사로그
- 정책 신선도 SLA
- 보안/개인정보/접근성 Release Gate
- B2B/B2G 제공 준비

## 현장 테스트 5대 시나리오
1. "투석환자가 여수에서 받을 수 있는 교통지원을 찾는다."
2. "장애등록 후 받을 수 있는 금전/요금 혜택을 찾는다."
3. "보호자가 대신 의료비/복지 지원 경로를 찾는다."
4. "급하게 생계/의료 지원이 필요해 긴급복지로 연결한다."
5. "정책 조건이 불확실할 때 앱이 확정판정하지 않고 공식기관 확인으로 안내한다."

## 운영 원칙
- 배포 전 항상 DEMO/BETA 라벨
- 병원 공식 로고/상표 사용은 허가 전 금지
- 실제 병원 시스템/API 연결 없음
- 개인정보/민감정보 입력 없이 핵심 기능 사용
- 정책은 공식출처 + 기준일
- 오류는 숨기지 말고 UNKNOWN/HOLD
- Demo 결과는 전국 V2 Golden fixture로 환류
